Consumo eléctrico del Aeroparque

—

Arrastrá el archivo .xlsx acá o elegilo desde tu equipo.

Se lee la hoja con columnas Mes, Medidor y Consumo_kWh. Si también están las hojas Pasajeros, Cargas Alimentadas y GRADOS DIAS, se usan automáticamente.

El año se usa sólo si la hoja no tiene columna Año. Cargar otro año lo agrega para comparar; cargar el mismo año lo reemplaza.

Consumo mensual por subestación

Total Aeroparque = SMEC (EDENOR 1/2) + medidores SET 02 (EDENOR 3). Tocá una barra para elegir el mes.

    Ranking de medidores

    Submedidores y la parte de SMEC sin submedición. Tocá una barra para ver el medidor.

    Detalle

    Consumo por medidor y por mes MWh

    El tono de cada celda es relativo al máximo de su propia fila. Tocá una fila para ver el medidor o el encabezado de un mes para filtrarlo.

    Los datos cargados se guardan sólo en este navegador. Mes parcial = consumo menor al 50 % de la mediana de los demás meses (probablemente lectura incompleta).
